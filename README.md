# Python To-Do List

## Project Overview

This project is a simple Python-based To-Do List application.

It allows users to add, view, complete, edit, and delete tasks.

Each task contains a username, task title, date, and status.

## Features

- Add a new task
- View all tasks
- Mark a task as completed
- Edit a task
- Delete a task
- Automatically record the date
- Store username with each task
- Input validation

## Technologies Used

- Python
- Python Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements
- datetime module

## How It Works

The program displays a menu with different options.

The user selects an option by entering a number.

Tasks are stored using a Python list, while each task is represented using a dictionary.

The program keeps the task details in memory while it is running.

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open `todo.py`.
4. Run the program.
5. Select an option from the menu.

## Task Details

Each task contains:

- ID
- Username
- Task title
- Date
- Status
